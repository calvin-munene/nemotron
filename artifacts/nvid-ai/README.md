# Nemotron hosting

This artifact hosts the existing Node service and interface in `ai-agent/`.
The React/Vite files are unused scaffold files; the service commands in
`.replit-artifact/artifact.toml` intentionally run the existing agent instead.

Production installs the agent's locked dependencies and starts its Node server.
`NVID_SCHEMA_MODE=verify` prevents startup-time database migrations. Replit's
Publish flow applies the development database schema.

Publish with public visibility so Telegram can reach `/webhooks/telegram`.
Use an always-running Reserved VM for the bot and its reminder worker.
After publishing, set `PUBLIC_URL` to the verified production HTTPS origin,
then add `TELEGRAM_BOT_TOKEN` and `TELEGRAM_WEBHOOK_SECRET` using Replit Secrets.
Republish after changing production configuration.

## Automatic encryption and Stars signing

When separate keys are absent, the server derives independent 32-byte keys from
`SESSION_SECRET` using HKDF-SHA-256 and stable, purpose-specific identifiers.
`SESSION_SECRET` must be a cryptographically random value with at least 32 bytes.
Derived values stay server-side in memory; they are not added to source, files,
environment variables, API responses, or logs.

Explicit `BOT_CREDENTIAL_ENCRYPTION_KEY` (32-byte Base64) and
`TELEGRAM_STAR_SIGNING_SECRET` (at least 32 bytes) take precedence. Invalid
explicit keys fail rather than silently using the derived key.

Keep `SESSION_SECRET` stable. Changing it, changing the derivation identifiers,
or switching from a derived encryption key to an explicit one requires an
intentional credential rotation/re-encryption process. Old payment payloads
signed with a previous key will also stop validating.

## Approved feature activation and payments

`NVID_FEATURE_ACTIVATION` is an explicit comma-separated list of approved feature
flags. Startup enables each through the existing audited store as the configured
super-admin, using a stable operation ID. It performs ordinary data updates,
not schema changes. The idempotency guard means later admin disables remain
disabled across restarts. Unsupported feature names or missing admin/database
configuration fail closed.

`TELEGRAM_PAYMENTS_ENABLED=true` enables optional Stars top-ups and checkout
without enabling `TELEGRAM_STARS_REQUIRED`. The ledger also supplies persistent
assistant preferences. Payment support routes to `TELEGRAM_ADMIN_USER_ID`.

Telegram command menus are cleared for default, all-private, and all-group
scopes. Menus are registered only in the configured owner's private chat and
the group-administrators scope. Existing command authorization remains in place.
Users can still type ordinary commands such as payment support manually.

`NVID_MODEL_ACTIVATION` enables a verified provider model through the same
audited, one-time operation approach after refreshing the provider catalog.
The current default is Nemotron 3.5 Lightning. Retired-model HTTP 410 responses
trigger one fallback, and retired choices are excluded for the process lifetime.
Payment support remains available to restricted accounts in private chats only.

## NVIDIA-only automatic tools

`NVIDIA_AUTO_TOOLS=true` enables automatic request routing. NVIDIA remains the
only AI provider. Explicit creation requests route to NVIDIA's hosted FLUX.1
generation endpoint; semantic requests are classified with constrained JSON.
Queued NVIDIA responses are polled through NVIDIA's own status endpoint.
Generated bytes are validated and sent directly to Telegram without storing
image bytes/base64 in the database. Threads and replied-to messages are preserved.

Current-information requests use free Google News and Bing RSS search sources:
no paid search API, additional AI provider, or search key is used. Answers include
retrieval dates, publication dates when supplied, and source URLs. Headlines and
snippets are not represented as fully verified articles. Source text is marked
untrusted, all fetch targets are fixed, and private credentials/contact details
are rejected from public search queries. Source citations remain in text history.

Image requests currently deliver through Telegram; web/mini-app chat supports
the free current-information tools and directs image requests to Telegram.
NVIDIA's hosted Kontext editing preview only accepts demo images, so arbitrary
upload edits fail explicitly without substitution or charging. Image-generation
timeouts, filtered output, unavailable endpoints, and empty search evidence
remain failures, and existing usage reservations are restored.

NVIDIA FLUX trial terms and the model's non-commercial license still apply.
Images are free-preview only: a request requiring a Stars-credit reservation
is refused and refunded rather than selling trial-model image generation.
Do not sell generated-image access without the required commercial permission.
No full editing NIM endpoint or paid replacement service has been configured.
